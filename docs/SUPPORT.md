# Atelier Salon support and updates

Seller and maintainer: **Naznin Kamal**  
Support: **najninkamalrimi@gmail.com**

Email support covers reproducible defects in the supplied theme, child theme and appointment plugin, installation guidance, and the included WordPress/Elementor Free layouts. Include the release number, WordPress/PHP/Elementor versions, a page URL or screenshot and reproduction steps. Do not email passwords, payment details, customer appointment messages or other private records.

Hosting administration, custom design/development, premium-plugin licenses, external scheduling/payment services and email-provider administration are outside the included code support scope. No fixed response time or lifetime update commitment is promised. Report security-sensitive findings privately by email; public GitHub Issues are suitable for non-sensitive bugs.

Updates are distributed through this repository as versioned ZIP packages with checksums. There is no automatic updater or license-key server. Back up the database/files, test on staging and upload the new parent theme or companion plugin. Keep custom PHP/CSS in the child theme. Existing starter pages and Elementor pages are not overwritten; insert a new pattern/template manually when adopting redesigned content.

Purchase, cancellation and refund questions should be sent to the seller through the purchase platform or support email. The storefront must display its purchase/refund terms before taking payment; mandatory consumer rights are not replaced by this documentation or the GPL warranty disclaimer. This repository does not process purchases.
